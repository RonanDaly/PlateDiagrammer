I want to design a GUI tool to create, edit, and display plate diagrams as used to describe statistical models. It should make diagram construction easy through drag-and-drop editing. The element palette should offer Circle node and Square node as the primary names, without the previous Random variable and Non-random variable headings. It should also offer a double circle node, a diamond node, and a factor node rendered as a small black square. Circle, square, double circle, and diamond nodes can be shaded to indicate known values or unshaded to indicate unknown values. Nodes can contain associated plain-text or LaTeX-style math labels.

The tool should support plates as rectangular containers whose corners can be switched between rounded and square. The palette should call this element Plate without the Rounded container subtitle. A plate can have associated text, including LaTeX-style math, which is attached to and rendered in the bottom-right corner of the plate so that it follows plate movement and resizing.

The tool should also support independent text nodes. Text is interpreted as LaTeX-style math when enclosed in dollar signs, for example $x_n$. Math should display subscripts, superscripts, Greek letters, bold symbols, and similar safe base-TeX notation without requiring arbitrary complex formula editing. The visual font size must remain consistent: adding both a superscript and a subscript must not shrink the base text compared with an otherwise equivalent label.

Nodes should be connectable with edges that stay attached to node boundaries as nodes move. Edge lines can be straight or smoothly sinusoidal. The target end can use a normal arrowhead, a perpendicular switch bar, or no head for an undirected edge. A switch bar should be pulled back slightly from the target node so it remains clearly visible. Edges can have associated plain or math text rendered alongside the edge and kept attached as the connected nodes move. Connections to plates or independent text elements and self-loops are not required.

Diagram elements can be selected individually, modifier-selected, marquee-selected, moved, grouped into flat non-nested groups, ungrouped, or deleted. Moving or deleting a group affects all of its members, while connected edges continue to follow grouped nodes. Grid snapping should be available and enabled by default. While snapping is enabled, holding Shift during a drag should temporarily disable snapping for that drag without changing the global snap setting.

The editor should autosave committed changes locally, import and export its versioned JSON document format safely, and export clean content-cropped SVG and high-resolution PNG diagrams without the editing grid or selection UI.
