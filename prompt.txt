I want to design a tool to create, edit and display plate diagrams as would be used to describe a statistical model. This tool should be a GUI tool that should make it easy to create and edit diagram elements using drag and drop techniques. The tool should be able to add non-random variables as square nodes and random variables as circle nodes. It should be possible for nodes to be shaded to indicate known values and unshaded to indicate unknown values. It should be possible to add plates as rectangles with slightly rounded corners. It should also be possible to add text nodes. Text nodes just display their associated text, but it should be possible to indicate that text is to be interpreted as LaTeX style math, using dollar sign indicators, e.g. $x_n$. This math needs to be able to display subscripts, superscripts, greek letters etc. and be capable of being bold etc, but doesn't need completely arbitrary editing of complex formulae. It will be possible for text to be associated with a nodes - this will be displayed inside the node and will be possibly math. It should be possible to connect nodes in the diagram with arrows, which are directed line segments. The arrowheads in the diagram should have two types, a normal arrow head and a bar head to indicate a switch. Similarly, the lines on arrows should be straight, or squiggly. When nodes are connected by arrows, then dragging a node elsewhere will keep the connection going. It should be possible to delete diagram elements by selecting them and pushing a delete button. It should be possible to select multiple diagram elements and perform operations on them, such as move or delete. It should be possible to group diagram elements so they act as one.
